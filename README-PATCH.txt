Ink2Web Lite 2.0.0 patch

Replace the matching files in the 1.9.5 project with these files.

New workflow:
1. Click a paragraph/equation block to edit it.
2. Click "Re-read from image".
3. Draw a rectangle around the corresponding handwriting on the original page.
4. Click "Re-read this region".
5. Review/edit the proposal.
6. Click "Use this transcription" to place it in the block editor.
7. Click Done in the block editor to commit the replacement.

The model never changes the page automatically. The proposed transcription remains editable and requires explicit acceptance.
